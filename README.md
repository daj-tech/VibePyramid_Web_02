# LocalLink

**LocalLink** is a web-based local information sharing platform designed to help users discover useful, relevant, and time-sensitive information within their local community.

Developed for **TEKTONIX'26 – Web Development Domain**.

---

## Project Information

**Project Name:** LocalLink  
**Hackathon:** TEKTONIX'26  
**Domain:** Web Development  
**Problem Statement:** Local Information Sharing Platform  
**Prototype Region:** Thane, Maharashtra, India  

---

## 1. Problem Statement

Useful local information is often scattered across WhatsApp groups, conversations, social media, and personal networks.

This makes it difficult for people to discover important information such as:

- Internships
- Scholarships
- Educational announcements
- Lost and found items
- Local issues
- Community events
- Emergency information
- Important local announcements

LocalLink provides a centralized platform where locally relevant information can be organized and discovered according to the user's selected area.

---

## 2. Objective

The main objective of LocalLink is to provide a simple and organized platform for discovering local information.

The platform aims to:

- Centralize local information.
- Organize information into meaningful categories.
- Allow users to select their local area.
- Display relevant information based on the selected area.
- Show upcoming events and deadlines.
- Provide information status such as Active, Upcoming, Expired, and Resolved.
- Provide calendar-based information.
- Support browser notifications and reminders.
- Provide Progressive Web App (PWA) functionality.
